1. Working protocol

  1. One task at a time, in TODO.md order.
  2. Test first. For every behaviour change, write the test, run it and watch it fail, implement, run it and watch it pass.
  3. Gate. Before every commit run: {{gate commands}}. Never commit on a red gate. Never weaken, skip or delete tests to get green.
  4. Review before commit. Run the review-and-fix skill on the staged change before every commit.
  5. Commit per task. Message format: {{repository convention, or "<area>: <imperative summary>"}}.
  6. Stage explicit paths only. Never git add -A, git add . or git commit -a. Never stage anything under plan/. Check git status --short before every commit.
  7. Never push, never add remotes, never publish.
  8. USER TASK items are for the human. Never perform or self-certify them; skip them and continue.
  9. Blocked: write BLOCKED: <reason and evidence> indented under the task, leave it unchecked, continue with independent tasks.
  10. Deferred is not done: never tick skipped work. Write DEFERRED: <reason> under an unchecked box.
  11. The plan's decisions are final. If one cannot be implemented, block and report.
